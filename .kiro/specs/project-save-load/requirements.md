# Project Save/Load — Требования

## Описание

Система сохранения и загрузки проектов в формате Godot Resource (.tres). Позволяет сохранять текущее состояние редактора (слои, изображения, настройки) и восстанавливать его позже.

## Функциональные требования

### 1. Сохранение проекта
- **FR1.1** Пользователь может сохранить проект через меню `File → Save`
- **FR1.2** Пользователь может сохранить проект как новый файл через `File → Save As`
- **FR1.3** При сохранении создаётся файл `.tres` с данными проекта
- **FR1.4** Сохраняемые данные:
  - Имя проекта (имя файла без расширения)
  - Размер холста (canvas_size)
  - Текущая вкладка (current_tab)
  - Список слоёв с метаданными (id, name, visible)
  - Изображения всех слоёв (image_data как PackedByteArray)

### 2. Загрузка проекта
- **FR2.1** Пользователь может открыть проект через меню `File → Open`
- **FR2.2** При загрузке восстанавливаются все слои с изображениями
- **FR2.3** Восстанавливаются размер холста и текущая вкладка

### 3. Новый проект
- **FR3.1** Пользователь может создать новый проект через меню `File → New`
- **FR3.2** При создании показывается диалог выбора размера холста
- **FR3.3** Очищается текущий холст и все слои

### 4. Автосохранение
- **FR4.1** Автосохранение при переключении вкладки (Draw ↔ Animation ↔ Evo)
- **FR4.2** Автосохранение каждую минуту
- **FR4.3** Сохранение привязано к action `save` (Ctrl+S)
- **FR4.4** Автосохранение не запрашивает путь — использует текущий файл проекта
- **FR4.5** Если проект ещё не сохранялся — автосохранение не выполняется

### 5. Импорт/Экспорт изображений (существующий функционал)
- **FR5.1** Импорт изображения как нового слоя (существующий)
- **FR5.2** Экспорт всего холста как PNG (существующий)
- **FR5.3** Экспорт всех слоёв как PNG в директорию (существующий)

## Нефункциональные требования

### Производительность
- **NFR1** Сохранение проекта с 10 слоями 64x64完成 за < 1 секунду
- **NFR2** Загрузка проекта с 10 слоями 64x64完成 за < 1 секунду

### Совместимость
- **NFR3** Формат .tres совместим с Godot 4.6+
- **NFR4** Данные изображений хранятся как PackedByteArray (platform-independent)

## Ограничения
- **LIM1** Сохраняются только данные вкладки Draw (Animation и Evo — в будущем)
- **LIM2** Инструменты и их настройки не сохраняются
- **LIM3** Цвета и история undo/redo не сохраняются

## Глоссарий

| Термин | Описание |
|--------|----------|
| Project | Файл .tres с полным состоянием проекта |
| Draw Layer | Изображение слоя в режиме рисования |
| Auto-save | Автоматическое сохранение без участия пользователя |
