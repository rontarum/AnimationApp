# Расширение системы инструментов

## Обзор

Расширение существующей системы инструментов редактора пиксельарта для добавления новых инструментов и улучшения функциональности существующих. Система должна поддерживать динамическое изменение размера кисти, рисование вторичным цветом, заливку, выделение областей и пипетку для выбора цвета.

## Пользовательские истории

### 1. Динамический размер кисти
**Как пользователь**, я хочу изменять размер кисти и ластика горячими клавишами, чтобы быстро переключаться между разными размерами без отвлечения на UI.

**Критерии приемки:**
- 1.1 Экшен "add" увеличивает размер кисти/ластика на 1 пиксель
- 1.2 Экшен "sub" уменьшает размер кисти/ластика на 1 пиксель  
- 1.3 Минимальный размер кисти: 1 пиксель
- 1.4 Максимальный размер кисти: 10 пикселей
- 1.5 Изменение размера работает для BrushTool и EraserTool
- 1.6 Размер кисти сохраняется при переключении между инструментами
- 1.7 Визуальный курсор отображает текущий размер кисти

### 2. Рисование вторичным цветом
**Как пользователь**, я хочу рисовать вторичным цветом правой кнопкой мыши, чтобы быстро переключаться между двумя цветами без смены активного цвета.

**Критерии приемки:**
- 2.1 Экшен "cancel" (правая кнопка мыши) в BrushTool рисует secondary_color
- 2.2 Экшен "action" (левая кнопка мыши) в BrushTool рисует primary_color
- 2.3 Функциональность работает как при клике, так и при перетаскивании
- 2.4 Курсор показывает, какой цвет будет использован

### 3. Инструмент заливки (FillTool)
**Как пользователь**, я хочу заливать области одинакового цвета, чтобы быстро закрашивать большие участки изображения.

**Критерии приемки:**
- 3.1 FillTool заливает связанную область одинакового цвета
- 3.2 Поддержка переключателя contiguous (связанная/вся область цвета)
- 3.3 При contiguous=true заливается только связанная область
- 3.4 При contiguous=false заливаются все пиксели данного цвета на слое
- 3.5 Заливка работает с primary_color (левая кнопка) и secondary_color (правая кнопка)
- 3.6 Заливка прозрачных пикселей работает корректно
- 3.7 Эффективный flood fill алгоритм без переполнения стека

### 4. Инструмент выделения (SelectionTool)
**Как пользователь**, я хочу выделять прямоугольные области и перемещать их содержимое, чтобы реорганизовывать элементы рисунка.

**Критерии приемки:**
- 4.1 SelectionTool позволяет выделить прямоугольную область перетаскиванием
- 4.2 Минимальный размер выделения: 1x1 пиксель
- 4.3 Во время выделения курсор скрыт, отображается только гизмо выделения
- 4.4 После выделения курсор появляется снова
- 4.5 При наведении на выделенную область курсор меняется на DRAG
- 4.6 Перетаскивание выделенной области перемещает все пиксели внутри
- 4.7 Экшен "deselect" снимает выделение
- 4.8 Гизмо выделения отрисовывается в canvas_renderer
- 4.9 Выделение работает только в пределах холста
- 4.10 При перемещении за пределы холста пиксели обрезаются

### 5. Инструмент пипетка (PickerTool)
**Как пользователь**, я хочу быстро выбирать цвет с холста, чтобы использовать существующие цвета в рисунке.

**Критерии приемки:**
- 5.1 Экшен "picker" активирует режим пипетки временно
- 5.2 В режиме пипетки курсор скрыт
- 5.3 Отображается гизмо: тонкий круг вокруг позиции мыши
- 5.4 Под гизмо отображается превью выбираемого цвета
- 5.5 Цвет выбирается с глобального viewport, не только с холста
- 5.6 Экшен "action" устанавливает цвет как primary_color
- 5.7 Экшен "cancel" устанавливает цвет как secondary_color
- 5.8 При отпускании "picker" возвращается предыдущий инструмент
- 5.9 PickerTool не имеет кнопки в UI (только горячая клавиша)

## Технические требования

### Архитектурные ограничения
- Все инструменты должны наследоваться от BaseTool
- Коммуникация только через EventBus и Services
- Состояние инструментов хранится в ToolService
- UI компоненты не содержат бизнес-логику
- Размер кисти хранится в AppState

### Производительность
- Flood fill должен работать за O(n) где n - количество заливаемых пикселей
- Выделение и перемещение должно работать плавно для областей до 100x100 пикселей
- Пипетка должна работать без задержек

### Совместимость
- Новые инструменты должны работать с существующей системой слоев
- Поддержка всех существующих экшенов input map
- Совместимость с системой курсоров

## Ограничения

- Выделение поддерживает только прямоугольные области
- Максимальный размер кисти ограничен 10 пикселями
- PickerTool работает только в пределах окна приложения
- Flood fill работает только в пределах одного слоя
