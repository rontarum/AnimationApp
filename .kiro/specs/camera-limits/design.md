# Лимиты камеры - Дизайн

## Архитектурное решение

Модификация существующего класса `CanvasCamera` с добавлением системы лимитов без нарушения текущей архитектуры.

## Компоненты

### 1. Константы лимитов
```gdscript
const MIN_ZOOM: float = 1.0
const MAX_ZOOM: float = 10.0
```

### 2. Методы ограничений

#### `_clamp_zoom(zoom_vector: Vector2) -> Vector2`
- Ограничивает зум в пределах MIN_ZOOM - MAX_ZOOM
- Применяется к `zoom_value` перед интерполяцией

#### `_clamp_position(pos: Vector2) -> Vector2`  
- Рассчитывает допустимые границы позиции на основе:
  - Размера холста (`AppState.canvas_size`)
  - Текущего зума (`zoom.x`)
  - Размера viewport
- Возвращает позицию в допустимых пределах

### 3. Интеграция в существующие методы

#### Модификация `_zoom()`
```gdscript
# После расчета zoom_value
zoom_value = _clamp_zoom(zoom_value)

# После расчета position
position = _clamp_position(_drag() + diff)
```

#### Модификация `_drag()`
```gdscript
# В конце метода
return _clamp_position(calculated_position)
```

## Алгоритм расчета границ позиции

1. **Получение размеров:**
   - canvas_size = размер холста в пикселях
   - viewport_size = размер окна просмотра
   - current_zoom = текущий зум камеры

2. **Расчет видимой области:**
   - visible_area = viewport_size / current_zoom
   - half_visible = visible_area / 2

3. **Определение границ:**
   - min_x = half_visible.x
   - max_x = canvas_size.x - half_visible.x  
   - min_y = half_visible.y
   - max_y = canvas_size.y - half_visible.y

4. **Применение ограничений:**
   - position.x = clamp(position.x, min_x, max_x)
   - position.y = clamp(position.y, min_y, max_y)

## Особенности реализации

### Сохранение плавности
- Лимиты применяются после интерполяции, не нарушая lerp()
- Плавные переходы при достижении границ

### Динамические границы
- Границы пересчитываются при каждом изменении зума
- Автоматическая адаптация к изменению размера холста

### Совместимость
- Не изменяет публичный API класса
- Сохраняет работу с EventBus и Services
- Поддерживает систему курсоров

## Тестирование

### Сценарии тестирования
1. Зум до минимального/максимального значения
2. Попытка перетащить камеру за пределы холста
3. Зум с одновременным перетаскиванием
4. Изменение размера холста при активных лимитах
5. Центрирование камеры при различных зумах
